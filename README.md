One 194-character sentence that talks a friend who has never coded into letting an AI agent build their first app idea on make.fun: describe the idea the way you'd tell a friend over coffee, try the first working version it builds, no code to learn, no pressure, and the idea stays yours. `main.py` writes the sentence to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to pick a different destination. Running it twice produces byte-identical output, since the sentence is fixed in the script and only written, never generated. The script also checks the sentence is one sentence of 1–240 characters before writing it.
